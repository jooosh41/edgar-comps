# edgar-comps

Turns SEC filings into a banker-style Excel model in one command: a comparable-companies
table and a DCF, built on live formulas that trace back to each 10-K.

Pulling five years of financials for eight companies by hand means opening about 40 filings.
This does it in seconds and shows where every number came from.

## Example: IMAX

`output/imax_comps.xlsx` is a full run on IMAX and six peers (Dolby, Marcus, AMC Entertainment,
Lionsgate Studios, Disney, Netflix), with prices from the November 13, 2026 close.

| | |
| --- | --- |
| Share price | $48.29 |
| Value implied by peer EV/EBITDA (17.3x median) | $42.15 |
| Value implied by the DCF (7.4% discount rate, 2.5% terminal growth) | $25.53 |
| Audit | 7 warnings across 18 checks |

The DCF sits well below the price because IMAX reinvests more than its capex line shows (equipment
placed under revenue-sharing deals, and film assets). `assumptions/IMAX.csv` documents that override.
`output/imax_comps_memo.md` is the written summary and audit. This is a model's output under stated
assumptions, not investment advice.

## Run it

```bash
pip install -r requirements.txt
cp .env.example .env            # then put your email in it; the SEC requires a declared contact
python -m edgar_comps --market  # IMAX and its peers, with live prices, beta and risk-free rate
python -m edgar_comps           # same, without market data: type prices into the yellow cells
python -m edgar_comps --peers media   # broader media set, DCF on Netflix
python -m edgar_comps NFLX DIS CMCSA --target DIS --out output/dis.xlsx
python -m edgar_comps --prices my_prices.csv    # CSV columns: ticker,price,date,source
python -m edgar_comps.verify output/imax_comps.xlsx   # formula errors, audit result, tie-out
python -m pytest                # 18 tests; the number checks need LibreOffice and skip without it
```

Output lands in `output/`. `output/imax_comps.xlsx` is the main run; `output/sample_media_comps.xlsx` is the broader media set.

## What the workbook contains

| Sheet | Contents |
| --- | --- |
| Inputs | Share prices, fetched with `--market` or typed in. |
| WACC | Discount rate from CAPM (risk-free rate, beta, equity risk premium) and a spread-based cost of debt. |
| Memo | A written valuation summary and a 15-check audit of the model, generated by fixed rules. |
| Comps | EV, market cap, EV/Revenue, EV/EBITDA, EV/EBIT, P/E, growth, margin, with mean/median/high/low. |
| DCF | Five-year unlevered free cash flow, Gordon-growth terminal value, implied share price, WACC x growth grid. |
| Checks | What the tool could not find for each company, and a debt reconciliation. |
| D_TICKER | Five years of filing data per company, the XBRL tag and filing accession behind each line. |

Colour convention: blue = hardcoded input or filing data, black = formula, green = link to another
sheet, yellow = a cell you are expected to fill in or challenge.

## The evaluator (Memo sheet)

The Memo sheet turns the model into words, with no AI involved. Each sentence is an Excel formula
built from a fixed rule, so the text rewrites itself when a price or assumption changes and every
claim traces to a cell.

1. **Valuation summary:** seven sentences covering the business, peers, leverage, market value,
   comps-implied value, DCF value and how the two methods compare with the share price.
2. **Model audit:** 15 checks that mark the model's own weak points as OK, WARNING or INFO. Examples:
   terminal value above 75% of enterprise value, a projected margin above the 3-year average,
   D&A more than twice capex, placeholder assumptions still in use, missing share prices.

`python -m edgar_comps.memo output/imax_comps.xlsx` exports the memo as Markdown. That step needs
LibreOffice installed to calculate the formulas; otherwise read the Memo sheet in Excel.

## How it works

1. `edgar.py` maps ticker to CIK and downloads the company's XBRL facts from `data.sec.gov` (cached in `data/cache`).
2. `facts.py` keeps full-fiscal-year values from 10-Ks. Each line item has a priority list of XBRL tags because
   companies tag the same line differently. Restated years use the latest filing.
3. `workbook.py` and `evaluator.py` write filing data as values and everything else as Excel formulas, so the model recalculates
   when you change a price or an assumption.

## Coverage

`python scripts/stress_test.py` runs the extractor on 38 companies across ten sectors. Last result:
20 clean, 11 usable with a disclosed approximation, 4 with gaps, 3 failed. Revenue matched the
10-K exactly for all nine companies checked by hand (Apple, Microsoft, Alphabet, Amazon, Nvidia,
Meta, Coca-Cola, Walmart, Netflix).

- **Works:** industrial, consumer, tech, telecom, energy and media companies that file 10-Ks.
- **Approximated, and said so on the Checks sheet:**
  - No operating-income line (J&J, Pfizer, Chevron, Exxon, Nike): EBIT = pre-tax income adjusted
    for interest, which pulls in one-off non-operating items.
  - No combined D&A tag (Microsoft, Alphabet, Tesla): depreciation + amortization of intangibles.
  - Ticker moved to a new registrant with no 10-K history (Exxon): history comes from the old
    registrant listed in `peers/predecessors.txt`.
- **Out of scope:** banks, insurers and REITs (EV/EBITDA and this DCF do not apply to them), and
  foreign companies that file a 20-F instead of a 10-K (Spotify, TSMC).
- **Cannot be fixed with this data source:** Visa and Berkshire (share counts are reported per
  share class, which the SEC summary API drops) and Ford (debt is tagged by segment with custom
  tags). These need the full XBRL filing, not the summary API.

## Assumptions

The tool derives what it can from data: the discount rate (WACC sheet), tax rate (3-year average
effective rate), margins, D&A and reinvestment (latest fiscal year). Anything you want to set yourself
goes in `assumptions/<TICKER>.csv` as `key,value,note`; the note is printed next to the override in the
workbook. Valid keys: `wacc`, `terminal_growth`, `tax_rate`, `ebit_margin`, `da_pct`, `capex_pct`,
`nwc_pct`, `growth_y1`. `assumptions/IMAX.csv` holds the one override used in the IMAX run.

## Verified against filings

IMAX's FY2025 figures were checked line by line against the financial statements in its 10-K:
revenue, operating income, pre-tax income, interest, tax, net income, D&A, operating cash flow,
capex, intangibles, investing cash flow, cash, both debt lines, non-controlling interest and diluted
shares all match. Dolby and Marcus were checked on revenue, operating income, pre-tax income, cash
and debt. The tests rebuild a workbook, calculate it, and compare the comps, WACC and DCF with
values worked out independently.

## Limits you should know before showing this to anyone

- **Three inputs are judgment, not data:** terminal growth (2.5%), the equity risk premium (5%) and the
  credit spread (2%). The audit keeps warning until terminal growth and working capital are set on purpose.
- **Market data is unofficial.** Prices and beta come from Yahoo Finance's chart endpoint, which can change
  or stop without notice. Beta is one stock's 5-year monthly regression and is noisy.
- **A five-year DCF undervalues fast growers.** Growth fades to the terminal rate by year 5, so companies
  the market expects to grow for a decade (Microsoft, Roku) come out far below their share price.
- **XBRL tagging is inconsistent.** The Checks sheet lists every gap and approximation; see Coverage above.
- **Reinvestment can hide outside capex.** The tool counts capex and purchased intangibles. Spending tagged
  elsewhere (IMAX's revenue-sharing equipment, a streamer's content) needs a `capex_pct` override; the
  audit's cash flow reconciliation flags when the projection outruns what the business actually generated.
- **Net debt counts cash only.** Short- and long-term investments (large at Dolby) are not netted
  against debt, and debt is the carrying value on the balance sheet, not face value.
- **EBIT is as reported.** One-off charges are not stripped out: IMAX's FY2025 operating income is after
  a $7.0M goodwill impairment and $2.5M of restructuring.
- **EBITDA is EBIT plus D&A.** For streamers this leaves content amortization inside EBITDA.
- **Share count is the cover-page count** of the latest filing where available. It excludes dilution from
  options and convertibles. Non-controlling interest is deducted at book value, not market value.
- **Fiscal years differ** (Disney ends in September), and there is no last-twelve-months calendarization yet.
- Private companies (A24) do not file with the SEC and cannot be included.
